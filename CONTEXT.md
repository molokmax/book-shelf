# Book Shelf

VK-бот для ведения личной библиотеки: добавление книг, отслеживание прогресса чтения и статистики.

## Language

**Книга**:
Запись в библиотеке пользователя: название, автор, число страниц, теги и прогресс чтения.
_Avoid_: Том, издание

**Статус чтения**:
Этап работы с книгой: хочу прочитать, читаю, прочитал, отложил.

**Прогресс чтения**:
Текущая прочитанная страница книги относительно общего числа страниц.
_Avoid_: Текущая страница (как название величины)

**Откат прогресса**:
Новое значение прогресса чтения меньше текущего.
_Avoid_: Уменьшение прогресса

**Скачок прогресса**:
Новое значение прогресса чтения больше текущего на величину, которая заметно превышает скорость чтения книги.
_Avoid_: Прыжок, резкое обновление

**Подозрительное обновление прогресса**:
Обновление прогресса чтения, которое является откатом или скачком. Применяется только после подтверждения.
_Avoid_: Странный ввод

**Некорректное значение прогресса**:
Значение прогресса чтения, которое нельзя принять: не целое число, отрицательное или больше числа страниц книги.
_Avoid_: Ошибка ввода (как название величины)

**Статистика чтения**:
Запись о количестве страниц, прочитанных за день.
_Avoid_: Лог чтения

**Скорость чтения**:
Среднее количество страниц в день по статистике за последние 30 дней.
_Avoid_: Темп

**Дневная цель**:
Количество страниц, которое пользователь планирует прочитать за календарный день (локальное время сервера). Одна цель на пользователя, считается по всем книгам суммарно.
_Avoid_: Норма, план чтения

**Прогресс дня**:
Сумма страниц, прочитанных пользователем за текущий календарный день по всем книгам.
_Avoid_: Дневная статистика

**Выполнение цели**:
Состояние, при котором прогресс дня больше или равен дневной цели. Вычисляется по статистике чтения и отдельно не хранится.
_Avoid_: Закрытая цель

**Прогноз завершения**:
Оценка окончания книги. Первичная величина: количество дней до завершения, остаток страниц, делённый на скорость чтения, с округлением вверх. Дата завершения: производная, сегодня плюс количество дней. 0 дней: книга завершена. Прогноз невозможен: данных о скорости нет.
_Avoid_: Расчёт даты завершения отдельно от количества дней
