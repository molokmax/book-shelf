# Book Shelf

VK-бот для ведения личной библиотеки: добавление книг, отслеживание прогресса чтения и статистики.

## Language

**Книга**:
Запись в библиотеке пользователя: название, автор, число страниц, теги и прогресс чтения.
_Avoid_: Том, издание

**Статус чтения**:
Этап работы с книгой: хочу прочитать, читаю, прочитал, отложил.

**Прогресс чтения**:
Текущая прочитанная страница книги относительно общего числа страниц.
_Avoid_: Текущая страница (как название величины)

**Статистика чтения**:
Запись о количестве страниц, прочитанных за день.
_Avoid_: Лог чтения

**Скорость чтения**:
Среднее количество страниц в день по статистике за последние 30 дней.
_Avoid_: Темп

**Прогноз завершения**:
Оценка окончания книги. Первичная величина: количество дней до завершения, остаток страниц, делённый на скорость чтения, с округлением вверх. Дата завершения: производная, сегодня плюс количество дней. 0 дней: книга завершена. Прогноз невозможен: данных о скорости нет.
_Avoid_: Расчёт даты завершения отдельно от количества дней
