# Book Shelf

VK-бот для ведения личной библиотеки: добавление книг, отслеживание прогресса чтения и статистики.

## Language

**Книга**:
Запись в библиотеке пользователя: название, автор, число страниц, теги и прогресс чтения.
_Avoid_: Том, издание

**Тег**:
Слово-метка из набора тегов пользователя, привязывается к книгам. Имя тега уникально в рамках набора пользователя без учёта регистра. Отображаемый порядок тегов книги фиксированно алфавитный.
_Avoid_: Тэг (как написание термина), категория, жанр

**Набор тегов пользователя**:
Персональный справочник тегов пользователя. Пополняется в момент сохранения книги с тегом, которого нет в наборе. Служит источником тегов для выбора при добавлении и редактировании книги.
_Avoid_: Справочник тегов системы, глобальный список тегов

**Статус чтения**:
Этап работы с книгой: хочу прочитать, читаю, прочитал, отложил.

**Прочитанная книга**:
Книга со статусом «Прочитал», независимо от значения прогресса чтения и даты завершения.
_Avoid_: Завершённая книга

**Прогресс чтения**:
Текущая прочитанная страница книги относительно общего числа страниц.
_Avoid_: Текущая страница (как название величины)

**Откат прогресса**:
Новое значение прогресса чтения меньше текущего.
_Avoid_: Уменьшение прогресса

**Скачок прогресса**:
Новое значение прогресса чтения больше текущего на величину, которая заметно превышает скорость чтения книги.
_Avoid_: Прыжок, резкое обновление

**Подозрительное обновление прогресса**:
Обновление прогресса чтения, которое является откатом или скачком. Применяется только после подтверждения.
_Avoid_: Странный ввод

**Некорректное значение прогресса**:
Значение прогресса чтения, которое нельзя принять: не целое число, отрицательное или больше числа страниц книги.
_Avoid_: Ошибка ввода (как название величины)

**Статистика чтения**:
Запись о количестве страниц, прочитанных за день.
_Avoid_: Лог чтения

**Достижение**:
Именная награда пользователя за действие или результат, связанный с ведением личной библиотеки и чтением книг. Достижения отражают личный прогресс и не предназначены для сравнения пользователей. Награда выдаётся автоматически, получается один раз и не отзывается при последующих изменениях данных.
_Avoid_: Ачивка, уровень, бейдж

**Получение достижения**:
Однократное закрепление награды за пользователем. Датой получения является день, когда бот впервые зафиксировал награду, в том числе по данным прошлых периодов. Повторная проверка условия новым получением не является.
_Avoid_: Разблокировка, открытие достижения

**Каталог достижений**:
Полный список полученных и ещё не полученных достижений пользователя с текущим прогрессом по измеримым целям. Все достижения и правила их получения открыты.
_Avoid_: Коллекция ачивок, список бейджей

**Настройки пользователя**:
Персональные параметры работы бота, принадлежат одному пользователю; у каждого пользователя свои значения.
_Avoid_: Конфигурация, глобальные настройки

**Период скорости чтения**:
Количество последних календарных дней, по которым вычисляется скорость чтения. Значения: 7, 14, 30; по умолчанию 30.
_Avoid_: Окно усреднения (как название настройки)

**Скорость чтения**:
Среднее количество страниц в день по статистике за период скорости чтения.
_Avoid_: Темп

**Дневная цель**:
Количество страниц, которое пользователь планирует прочитать за календарный день (локальное время сервера). Одна цель на пользователя, считается по всем книгам суммарно.
_Avoid_: Норма, план чтения

**Прогресс дня**:
Сумма страниц, прочитанных пользователем за текущий календарный день по всем книгам.
_Avoid_: Дневная статистика

**Выполнение цели**:
Состояние, при котором прогресс дня больше или равен дневной цели. Вычисляется по статистике чтения и отдельно не хранится.
_Avoid_: Закрытая цель

**Страйк**:
Количество последовательных календарных дней, в каждый из которых выполнена дневная цель. До выполнения сегодняшней цели сохраняется страйк, закончившийся вчера.
_Avoid_: Серия чтения, серия выполнения цели

**Мотивационная фраза**:
Короткая фраза, которую бот случайным образом добавляет к отклику на успешное обновление прогресса чтения. Хранится в глобальном списке, одинаковом для всех пользователей, и пополняется миграциями. Не показывается при неизменённом прогрессе и в отклике с поздравлением о выполненной дневной цели.
_Avoid_: Поощряющее сообщение, подбадривающая фраза (как синонимы термина)

**Категория фразы**:
Атрибут мотивационной фразы, задающий будущий сценарий её показа: general, trend_up, trend_down, goal_reached. В текущей версии выбор фразы категорию не использует.
_Avoid_: Тип фразы, жанр фразы

**Промежуточное сообщение**:
Сообщение бота, которое переспрашивает пользователя и ждёт продолжения сценария: промпты шагов, ошибки валидации ввода, промежуточные подтверждения. Удаляется ботом из истории чата.
_Avoid_: Временное сообщение, служебное сообщение

**Финальное сообщение**:
Сообщение бота, завершающее команду: результат (список, карточка, статистика), пустой результат («Книг с таким статусом нет»), сообщение об отмене или сбросе сценария. Остаётся в истории чата.
_Avoid_: Результат команды (как зонтичный термин)

**Прогноз завершения**:
Оценка окончания книги. Первичная величина: количество дней до завершения, остаток страниц, делённый на скорость чтения, с округлением вверх. Дата завершения: производная, сегодня плюс количество дней. 0 дней: книга завершена. Прогноз невозможен: данных о скорости нет.
_Avoid_: Расчёт даты завершения отдельно от количества дней

**Главное меню**:
Основной набор команд, который бот показывает пользователю по умолчанию: самые востребованные команды и кнопка «Ещё».
_Avoid_: Главная клавиатура (как название меню)

**Подменю «Ещё»**:
Набор остальных команд, открывается кнопкой «Ещё» из главного меню; содержит кнопку «Назад» для возврата в главное меню.
_Avoid_: Дополнительное меню, расширенное меню

**Сценарий**:
Многошаговый диалог команды, который хранит состояние пользователя в `user_state` и продолжается следующими сообщениями до финала или отмены. Пока сценарий активен, команды других сценариев блокируются, кроме системных `/start` и `/cancel`.
_Avoid_: Диалог, воронка, FSM

**Шаг сценария**:
Текущее состояние сценария, которое определяет, как обработать следующее сообщение и какой вопрос задать пользователю.
_Avoid_: Стадия, этап
