## Why

Роутинг и обработка команд в боте стали хаотичными: логика разбросана по отдельным функциям, нет приоритетов и явного управления состоянием. Это усложняет добавление новых команд, тестирование и поддержку.

## What Changes

- Вынести всю логику роутинга в отдельный класс‑обработчик `CommandRouter`.
- Добавить базовый класс `AbstractCommandHandler` с поддержкой списка команд, приоритета и метода `can_handle`.
- Реализовать конкретные обработчики как наследники этого класса, где каждый шаг обработки – отдельный метод.
- Ввести хранилище состояния пользователя в SQLite (новый репозиторий `UserStateRepository`).
- Обновить `bot.py` для использования роутера и контекста.

## Capabilities

### New Capabilities
- `routing-refactor`: структурированный роутинг команд с приоритетами, поддержкой состояний и расширяемой системой обработчиков.

### Modified Capabilities
- *нет*

## Impact

- Добавятся новые файлы: `src/vk_bot/command_router.py`, `src/vk_bot/handlers/base.py`, `src/vk_bot/repository/user_state.py`, `src/vk_bot/context.py`.
- Перепишутся существующие обработчики (`add.py`, `edit.py`, `list.py` и др.) под новую архитектуру.
- Появятся миграции SQLite для таблицы `user_state`.
- Не изменятся публичные API бота, но изменится внутренний код, что потребует обновления тестов.
