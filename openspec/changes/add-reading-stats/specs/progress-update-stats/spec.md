# Specification for progress-update-stats

## Purpose

Спецификация описывает вывод мини-статистики чтения книги в ответе на успешное обновление прогресса через команду `/edit` VK-бота Book Shelf.

## ADDED Requirements

### Requirement: Мини-статистика после обновления прогресса

Система **SHALL** после успешного обновления прогресса чтения книги отправлять пользователю сообщение с подтверждением и блоком мини-статистики по этой книге. Расчёт использует существующие методы `ReadingStatsService` (`get_reading_stats`, `avg_pages_per_day`, `predict_completion_date`) и данные таблицы `read_stats`, включая только что записанные страницы.

#### Scenario: Успешное обновление прогресса с данными статистики

- **WHEN** пользователь в состоянии `waiting_for_progress_input` вводит корректный номер страницы в диапазоне `0..total_pages`, и `BookService.update_book_progress` выполняется успешно
- **THEN** система отправляет сообщение, содержащее подтверждение обновления прогресса и строки:
  - `Прогресс: {current_page}/{pages} ({percent}%)`, где `percent` — целая часть процента прочитанного
  - `За последнюю неделю прочитано: {weekly} стр.`, где `weekly` — сумма `pages_read` из `read_stats` за последние 7 календарных дней
  - `За последний месяц прочитано: {monthly} стр.`, где `monthly` — сумма `pages_read` за последние 30 календарных дней
  - `Среднее за 30 дней: {avg:.2f} стр/день`, где `avg` — среднее страниц в день за последние 30 дней
  - `Ожидаемая дата завершения: {YYYY-MM-DD}`, где дата вычисляется как `today + ceil(осталось_страниц / avg)`

#### Scenario: Недостаточно данных для оценки

- **WHEN** после успешного обновления прогресса среднее число страниц в день за последние 30 дней равно нулю
- **THEN** система вместо строк о среднем значении и ожидаемой дате выводит строку `Недостаточно данных для оценки завершения`, остальные строки блока статистики сохраняются

#### Scenario: Ошибка ввода не порождает статистику

- **WHEN** пользователь вводит нечисловое значение, отрицательное число или страницу вне диапазона `0..total_pages`
- **THEN** система отправляет только сообщение об ошибке и НЕ выводит блок мини-статистики

### Requirement: Общий хелпер форматирования блока статистики

Система **SHALL** содержать хелпер `format_progress_stats(book, weekly_pages, monthly_pages, avg_pages, predicted_date)` в `src/utils/helpers.py`, возвращающий блок мини-статистики в порядке, зафиксированном в первом требовании. Формат строк совпадает с соответствующими строками `format_book_details`.

#### Scenario: Форматирование полного блока

- **WHEN** хелпер вызывается с `weekly_pages=20`, `monthly_pages=55`, `avg_pages=2.89`, `predicted_date=date(2027, 1, 7)` и книгой с `current_page=55`, `pages=319`
- **THEN** результат содержит в указанном порядке строки `Прогресс: 55/319 (17%)`, `За последнюю неделю прочитано: 20 стр.`, `За последний месяц прочитано: 55 стр.`, `Среднее за 30 дней: 2.89 стр/день`, `Ожидаемая дата завершения: 2027-01-07`

#### Scenario: Форматирование при нулевом среднем

- **WHEN** хелпер вызывается с `avg_pages=0` и `predicted_date=None`
- **THEN** результат содержит `Недостаточно данных для оценки завершения` и не содержит строк о среднем значении и ожидаемой дате завершения
