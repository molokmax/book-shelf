# Specification for stats-command

## Purpose

Спецификация описывает требования к команде `/stats` в VK-боте Book Shelf. Команда отображает статистику чтения пользователя.

## Requirements

### Requirement: Пользователь может получить статистику чтения

Система **SHALL** позволять пользователю VK-бота получить общую статистику по его книгам.

#### Scenario: Успешное получение статистики
- **WHEN** пользователь отправляет команду `/stats` или нажимает соответствующую кнопку
- **THEN** система формирует сообщение со статистикой, содержащее:
  - общее количество книг,
  - количество прочитанных книг,
  - количество книг в процессе чтения,
  - количество книг в статусе «хочу прочитать»,
  - количество отложенных книг,
  - общее количество страниц,
  - общее количество прочитанных страниц,
  - средний процент прогресса по всем книгам,
  - и отправляет его пользователю через VK API
