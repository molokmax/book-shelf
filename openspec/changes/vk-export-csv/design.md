## Context

В текущей версии VK‑бота отсутствует возможность экспортировать список книг пользователя. Пользователи могут лишь просматривать книги внутри бота, что ограничивает аналитические возможности и резервное копирование данных.

## Goals / Non‑Goals

**Goals:**
- Добавить экспорт списка книг в CSV‑файл через кнопку в диалоге помощи.
- Обеспечить совместимость с текущей структурой данных (`models.Book`).
- Минимизировать изменения в существующей логике бота.

**Non‑Goals:**
- Не поддерживаем экспорт в другие форматы (JSON, XML) в этом изменении.
- Не меняем схему данных или модели книги.

## Decisions

- **CSV генерация:** использовать встроенный модуль `csv` и написать утилиту `export_to_csv` в `src/vk_bot/utils/export.py`.
- **Временный файл:** сохранять CSV во временную директорию (`tempfile.TemporaryDirectory`) и сразу отправлять пользователю через VK API, после чего файл удаляется.
- **Кнопка в help:** добавить кнопку «Экспорт CSV» в обработчик `src/vk_bot/handlers/help.py`; клавиатуру `keyboards.py` менять не требуется.
- **Обработчик экспорта:** реализовать отдельный колбэк `export_csv` в `src/vk_bot/handlers/export.py`.
- **Логирование:** добавить запись в лог о начале и завершении экспорта.

## Risks / Trade‑offs

- **Большие списки:** генерация CSV может потребовать значительное время и память при большом количестве книг. mitigated by streaming rows.
- **Безопасность:** временный файл должен удаляться, чтобы не оставлять пользовательские данные на диске.
- **Тестируемость:** нужен мок VK API для проверки отправки файла.

## Migration Plan

Нет необходимости миграции схемы данных; изменение ограничивается добавлением нового обработчика и утилиты.
