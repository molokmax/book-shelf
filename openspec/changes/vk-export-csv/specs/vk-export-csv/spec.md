## ADDED Requirements

### Requirement: Пользователь может экспортировать список книг в CSV‑файл
Система **SHALL** позволять пользователю VK‑бота экспортировать его личный список книг в CSV‑формате.

#### Scenario: Успешный экспорт
- **WHEN** пользователь нажимает кнопку «Экспорт CSV» в разделе помощи
- **THEN** система генерирует CSV‑файл, содержащий заголовки `id,title,author,tags,pages,current_page,status,created_at` и строки с данными каждой книги пользователя, сохраняет его во временный каталог и отправляет файл пользователю через VK API.
