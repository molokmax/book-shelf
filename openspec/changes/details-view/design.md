## Context

Текущий бот позволяет просматривать список книг и выполнять базовые операции (добавление, редактирование, удаление). Пользователю необходимо получать полную информацию о выбранной книге, но сейчас нет удобного способа выбрать книгу и увидеть её детали.

## Goals / Non-Goals

**Goals:**
- Добавить кнопку `/details`, которая после нажатия выводит пронумерованный список книг (аналогично команде `edit`).
- Пользователь вводит номер книги из списка, бот получает соответствующую запись и формирует сообщение с полной информацией о книге.
- Формирование текста сообщения происходит непосредственно в обработчике команды `details`; дополнительный метод в сервис‑слое не требуется.

**Non-Goals:**
- Не менять структуру базы данных или модели книги.
- Не добавлять новые внешние зависимости.

## Decisions

- **Обработчик в `src/bot/handlers/details.py`**: реализует два шага — сначала отправляет список книг с номерами, затем ожидает ввод номера от пользователя и формирует сообщение с деталями.
- **Кнопка в `src/bot/keyboards.py`**: добавить `details_button` и включить её в клавиатуру книги.
- **Логика в хэндлере**: после получения номера используется уже существующий репозиторий/сервис для получения книги (`BookRepository.get_by_id` или аналогичный), затем формируется текст сообщения с полями: название, автор, тэги, статус, общее количество страниц, количество прочитанных страниц, дата добавления, дата начала чтения, ссылка.
- **Тесты**: добавить юнит‑тесты для нового обработчика, проверяющие вывод списка и правильность формирования сообщения после выбора номера.
- **Не добавляем метод в сервис‑слой**: все необходимые операции выполняются через уже существующие сервисы/репозитории.

## Risks / Trade-offs

- **Риск**: Пользователь может ввести неверный номер.
  **Mitigation**: добавить валидацию ввода и запрос повторить ввод при ошибке.
- **Риск**: Формирование большого сообщения может превысить лимит длины сообщения ВКонтакте.
  **Mitigation**: использовать сокращения и проверять длину перед отправкой.
- **Риск**: Добавление новой кнопки может конфликтовать с текущими клавиатурами.
  **Mitigation**: вынести общие элементы клавиатуры в отдельные функции и протестировать комбинацию.
