# Specification for user-settings

## Purpose

Дельта от change `add-motivational-phrases`: добавляет в capability настройки пользователя настройку «Мотивация» (вкл/выкл) и её переключатель на экране `/settings`. Базовые требования capability (период скорости чтения и команда `/settings`) живут в дельте активного change `add-user-settings` и здесь не повторяются, чтобы при поочерёдной архивации не было дубликатов. Маркер ADDED, а не MODIFIED: capability ещё не смёржена в `openspec/specs/`.

## ADDED Requirements

### Requirement: Хранение настройки «Мотивация»

Система **SHALL** хранить настройку «Мотивация» в колонке `motivation_enabled` таблицы `user_settings`: включена (`1`) или выключена (`0`). Отсутствие строки пользователя **SHALL** означать, что мотивация включена. Повторное сохранение **SHALL** перезаписывать значение той же строки с обновлением `updated_at`.

#### Scenario: Включена по умолчанию

- **WHEN** у пользователя нет строки в `user_settings`
- **THEN** мотивация считается включённой

#### Scenario: Хранение на существующей базе

- **WHEN** база создана до этого change и строка настроек пользователя уже существует
- **THEN** колонка `motivation_enabled` добавляется миграцией со значением по умолчанию «включена»

#### Scenario: Повторное переключение

- **WHEN** пользователь несколько раз переключает мотивацию
- **THEN** для одного пользователя остаётся одна строка настроек с актуальным значением

### Requirement: Переключатель мотивации на экране настроек

Экран `/settings` **SHALL** показывать состояние мотивации строкой «Мотивация: включена» / «Мотивация: выключена» и содержать одну кнопку-переключатель с меткой текущего состояния «Мотивация: Вкл» / «Мотивация: Выкл». Цвет кнопки **SHALL** отражать состояние: активный цвет при включённой мотивации, нейтральный при выключенной. Нажатие **SHALL** инвертировать настройку: сохранить значение, отправить подтверждение «Мотивация включена» / «Мотивация выключена» и оставить сценарий настроек активным.

#### Scenario: Состояние на экране

- **WHEN** мотивация пользователя выключена, он открывает `/settings`
- **THEN** экран содержит «Мотивация: выключена» и кнопку состояния

#### Scenario: Выключение

- **WHEN** в меню настроек пользователь нажимает кнопку переключателя при включённой мотивации
- **THEN** настройка сохранена как выключенная, отправлено «Мотивация выключена», сценарий настроек остаётся активен

#### Scenario: Обратное включение

- **WHEN** пользователь без строки настроек снова нажимает кнопку переключателя дважды
- **THEN** после второго нажатия мотивация снова включена, сценарий остаётся активен
