# Specification for motivation

## Purpose

Спецификация описывает мотивационную поддержку пользователя: глобальный список мотивационных фраз, выбор случайной фразы при успешном обновлении прогресса чтения и правило показа. Сценарный подбор по категориям зарезервирован на будущее и в текущей версии не применяется.

## ADDED Requirements

### Requirement: Таблица мотивационных фраз

Система **SHALL** хранить мотивационные фразы в таблице `motivational_phrases`: глобальный список, одинаковый для всех пользователей. Строка **SHALL** содержать уникальный текст фразы и категорию (`general`, `trend_up`, `trend_down`, `goal_reached`), по умолчанию `general`. Таблица **SHALL** создаваться и наполняться идемпотентно при каждом старте приложения.

#### Scenario: Начальный список

- **WHEN** приложение стартует на пустой базе данных
- **THEN** в `motivational_phrases` 15 фраз, все с категорией `general`

#### Scenario: Повторный старт

- **WHEN** приложение стартует, база уже содержит 15 фраз
- **THEN** новых строк не появляется, дубликатов фраз нет

#### Scenario: Пустая таблица

- **WHEN** приложение стартует и таблица `motivational_phrases` пуста (сборка без сида)
- **THEN** ошибка не возникает, фразу выбрать нельзя

### Requirement: Случайный выбор фразы

Сервис мотивации **SHALL** выбирать одну случайную фразу из таблицы. Категория в текущей версии **SHALL** игнорироваться при выборе. Для пустой таблицы сервис **SHALL** возвращать отсутствие фразы, а не ошибку. Контекст обновления (предыдущая страница, новая страница, прирост, завершение книги, выполнение дневной цели) **SHALL** передаваться сервису и не влияет на выбор в текущей версии.

#### Scenario: Выбор из списка

- **WHEN** таблица содержит 15 фраз
- **THEN** сервис возвращает текст одной из них, и повторный вызов может вернуть другую фразу

#### Scenario: Пустая таблица

- **WHEN** таблица не содержит фраз
- **THEN** сервис возвращает отсутствие фразы без ошибки

### Requirement: Фраза в ответе на обновление прогресса

После успешного применения обновления прогресса текст ответа **SHALL** дополняться случайной мотивационной фразой. Фраза **SHALL** быть последним блоком сообщения, отделяемым пустой строкой от предыдущего блока.

#### Scenario: Обновление с фразой

- **WHEN** пользователь обновляет прогресс книги (мотивация включена)
- **THEN** сообщение содержит фразой отдельный блок после заголовка и прогресса

#### Scenario: Завершение книги

- **WHEN** пользователь доводит прогресс до последней страницы и книга переходит в статус «прочитал»
- **THEN** сообщение содержит случайную фразу из списка с универсальной формулировкой

### Requirement: Исключения показа фразы

Мотивационная фраза **SHALL** не показываться, если обновление ничего не изменило («Прогресс не изменился») или если в сообщение уже добавлена строка выполнения дневной цели («🎉 Цель на день выполнена!»). Сбой выбора фразы **SHALL** не ломать отправку подтверждения прогресса.

#### Scenario: Прогресс не изменился

- **WHEN** пользователь вводит текущую страницу без изменений
- **THEN** сообщение начинается с «ℹ️ Прогресс не изменился», фраза не добавляется

#### Scenario: Выполнение дневной цели

- **WHEN** обновление прогресса приводит к выполнению дневной цели
- **THEN** показывается «🎉 Цель на день выполнена!», случайная фраза не добавляется

#### Scenario: Сбой сервиса мотивации

- **WHEN** сервис мотивации возвращает ошибку при применении прогресса
- **THEN** подтверждение прогресса доставляется, сообщения об ошибке пользователю нет

### Requirement: Формулировки начального списка

Начальный список из 15 фраз **SHALL** состоять из формулировок, уместных при любом обновлении прогресса: росте страниц, откате после подтверждения и завершении книги. Обращение фразы **SHALL** быть неформальным («ты»).

#### Scenario: Тон не привязан к сценарию

- **WHEN** происходит завершение книги
- **THEN** любая фраза списка остаётся уместной в ответе (например, «🌟 Так держать!», а не «Продолжай читать эту книгу!»)

## Notes (не требования)

Будущий сценарный подбор будет выбирать категорию по контексту обновления (тренд страниц растёт/падает, цель достигнута) и не является частью этой версии.
