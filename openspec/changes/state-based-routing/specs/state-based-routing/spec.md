## ADDED Requirements

### Requirement: CommandRouter учитывает активный стейт пользователя

При маршрутизации сообщения `CommandRouter.route()` ДОЛЖЕН направлять сообщение обработчику не только если введённая команда совпадает с `commands` обработчика, но и если у пользователя есть активный стейт, и команда из стейта совпадает с `commands` этого обработчика.

#### Scenario: Сообщение направляется обработчику по активному стейту

- **WHEN** пользователь находится в активном стейте с command = "/add"
- **WHEN** пользователь отправляет текст, не являющийся командой (например, "Война и мир")
- **WHEN** ни один обработчик не совпал по введённому тексту
- **THEN** `CommandRouter` ДОЛЖЕН найти обработчик, у которого "/add" есть в `commands`
- **THEN** этот обработчик ДОЛЖЕН получить управление через `handle()`

#### Scenario: Обработчик с высоким приоритетом перехватывает сообщение до проверки стейта

- **WHEN** пользователь находится в активном стейте с command = "/add"
- **WHEN** пользователь вводит команду "отмена"
- **THEN** `CancelHandler` (приоритет 100) ДОЛЖЕН получить управление через свой `can_handle`
- **THEN** сообщение НЕ ДОЛЖНО дойти до обработчика, соответствующего стейту `/add`

#### Scenario: Приоритет обработчиков сохраняется при поиске по стейту

- **WHEN** пользователь находится в активном стейте
- **WHEN** несколько обработчиков имеют в `commands` команду, соответствующую стейту
- **THEN** выбирается обработчик с наивысшим приоритетом

#### Scenario: Fallback-диспатчинг удалён

- **WHEN** `CommandRouter.route()` возвращает `None`
- **THEN** в `handle_event()` НЕ ДОЛЖНО быть дополнительной обработки команд `/list`, `/edit`, `/details` и их step-вариантов
- **THEN** сообщение просто логируется как необработанное

### Requirement: Обратная совместимость

Поведение для сообщений без активного стейта НЕ ДОЛЖНО измениться. Если у пользователя нет активного стейта, маршрутизация ДОЛЖНА работать как и раньше — только по введённой команде.

#### Scenario: Нет активного стейта — поведение не меняется

- **WHEN** у пользователя нет активного стейта
- **WHEN** пользователь отправляет команду "/list"
- **THEN** `ListHandler` ДОЛЖЕН получить управление
- **THEN** `AddHandler` НЕ ДОЛЖЕН получить управление, даже если команда из стейта была бы "/add"
