# Specification for refactor-details-handler

## MODIFIED Requirements

### Requirement: Пользователь может просматривать детальную информацию о книге

Система **SHALL** позволять пользователю VK‑бота выбрать книгу по фильтру (статус, тег, все книги) и просмотреть её детальную информацию.

*Примечание: изменение чисто структурное — реализация переносится из `details.py` в `DetailsHandler` класс. Требования к поведению не меняются.*

#### Scenario: Выбор фильтра — по статусу
- **WHEN** пользователь вводит `/details` и выбирает «По статусу»
- **THEN** система показывает клавиатуру выбора статуса книги

#### Scenario: Выбор фильтра — по тегам
- **WHEN** пользователь вводит `/details` и выбирает «По тегам»
- **THEN** система показывает клавиатуру выбора тега

#### Scenario: Выбор фильтра — все книги
- **WHEN** пользователь вводит `/details` и выбирает «Все»
- **THEN** система показывает нумерованный список всех книг пользователя

#### Scenario: Выбор книги и показ деталей
- **WHEN** пользователь вводит номер книги из списка
- **THEN** система отправляет детальную информацию о книге, включая статистику чтения
