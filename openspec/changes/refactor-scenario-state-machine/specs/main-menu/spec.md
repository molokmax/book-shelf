# Specification for main-menu

## MODIFIED Requirements

### Requirement: Не перехватывать чужие сценарии

Обработчик навигации **SHALL** при активном сценарии другой команды ответить сообщением «⚠️ Сейчас активна другая операция. Заверши её или нажми «Отмена».» и **SHALL NOT** изменять состояние этого сценария. Системная команда «Отмена» продолжает перехватываться `CancelHandler` глобально; `/start` сбрасывает сценарий и показывает приветствие.

#### Scenario: «Ещё» внутри чужого сценария

- **WHEN** пользователь в активном сценарии `/add` нажимает «Ещё» (клавиатура осталась от предыдущего сообщения)
- **THEN** бот отвечает сообщением об отказе, состояние `/add` и его текущий промпт сохраняются

#### Scenario: «Назад» внутри чужого сценария

- **WHEN** пользователь в активном сценарии `/edit` нажимает «Назад»
- **THEN** бот отвечает сообщением об отказе, сценарий `/edit` продолжается

#### Scenario: Отмена работает глобально

- **WHEN** пользователь вводит «Отмена»
- **THEN** `CancelHandler` сбрасывает состояние и выводит сообщение об отмене
