## Why

Обновление прогресса чтения - самая частая операция, но сейчас она спрятана внутри `/edit`: нужно выбрать фильтр, найти книгу, открыть меню действий и только потом ввести страницу. Для книг, которые пользователь читает сейчас, этот путь избыточен.

## What Changes

- Добавляется команда `/progress` с алиасами `progress` и `прогресс`.
- Команда сразу показывает нумерованный список книг со статусом `reading`, без промежуточного меню действий.
- В список добавляется кнопка `Другие`, которая открывает стандартный диалог выбора книги по статусу, тегам или всем книгам.
- После выбора книги сразу запрашивается текущая страница.
- Сохраняются текущие проверки прогресса, подтверждение отката и скачка, мини-статистика и автоматическое обновление статуса.
- Кнопка `Прогресс` и её ветка удаляются из меню действий `/edit`.
- В меню действий `/edit` добавляется общий ответ на неизвестное действие.
- Legacy-состояния обновления прогресса временно остаются в `/edit` и делегируют в общий компонент.
- Общий выбор книги выносится в переиспользуемый компонент для нового handler-а. Остальные handler-ы переводятся позже.
- `/progress` не перехватывает управление у активного сценария другой команды.
- Обновляются `/start`, `/help`, README и тесты.

## Capabilities

### New Capabilities
- `progress-update-command`: выбор книги для обновления прогресса, ввод и подтверждение значения, поведение при активных сценариях и удаление прогресса из `/edit`.

### Modified Capabilities

Нет. Существующие спецификации в `openspec/specs/` не меняются.

## Impact

- Новый handler `src/vk_bot/handlers/progress.py`.
- Изменения в `src/vk_bot/handlers/edit.py`, `src/vk_bot/bot.py`, `src/vk_bot/keyboards.py`, `src/vk_bot/handlers/start.py`, `src/vk_bot/handlers/help.py`.
- Новые переиспользуемые компоненты выбора книги и обновления прогресса.
- Тесты в `tests/handlers/` и общие тесты сервисов.
- README и пользовательская документация команд.
