# Specification for user-settings

## Purpose

Спецификация описывает персональные настройки пользователя: хранение и изменение через команду `/settings` в VK-боте Book Shelf. Первая настройка: период скорости чтения (за сколько дней считать среднее количество прочитанных страниц в день).

## ADDED Requirements

### Requirement: Хранение настроек пользователя

Система **SHALL** хранить персональные настройки в таблице `user_settings`: одна строка на пользователя. Период скорости чтения **SHALL** быть целым числом из набора 7, 14, 30. Повторное сохранение **SHALL** перезаписывать значение и `updated_at`, не создавая второй строки. Отсутствие строки **SHALL** означать период 30.

#### Scenario: Сохранение периода

- **WHEN** пользователь без сохранённых настроек выбирает период 14
- **THEN** в `user_settings` появляется одна строка с `reading_speed_period_days = 14`

#### Scenario: Изменение периода

- **WHEN** пользователь с периодом 14 выбирает 7
- **THEN** остаётся одна строка со значением 7 и обновлённым `updated_at`

#### Scenario: Отсутствие настройки

- **WHEN** у пользователя нет строки в `user_settings`
- **THEN** период скорости чтения считается равным 30

### Requirement: Команда /settings

Система **SHALL** отвечать на команду `/settings` (при отсутствии активного сценария другой команды) экраном с текущими значениями настроек и клавиатурой «7 дней», «14 дней», «30 дней», «Назад». Сценарий переходит в состояние `menu`.

#### Scenario: Вход в настройки

- **WHEN** пользователь без активного сценария вводит `/settings`
- **THEN** система отправляет экран настроек с текущим значением периода и клавиатурой выбора

#### Scenario: Текущее значение на экране

- **WHEN** период пользователя 14, он вводит `/settings`
- **THEN** экран содержит строку «Период скорости чтения: 14 дней»

### Requirement: Изменение периода скорости чтения

Выбор значения **SHALL** применять его немедленно, отправлять сообщение с новым значением и той же клавиатурой, оставляя сценарий активным.

#### Scenario: Выбор периода

- **WHEN** в меню настроек пользователь нажимает «14 дней»
- **THEN** период 14 сохранён, отправлено сообщение «Период скорости чтения: 14 дней» с клавиатурой настроек, сценарий остаётся активен

#### Scenario: Повторный выбор

- **WHEN** сразу после выбора 14 дней пользователь нажимает «7 дней»
- **THEN** период 7 сохранён, отправлено сообщение с новым значением, сценарий остаётся активен

### Requirement: Выход из настроек

Кнопка «Назад» **SHALL** завершать сценарий настроек: сообщение «Возврат в главное меню» с главной клавиатурой и очистка состояния пользователя.

#### Scenario: Нажатие «Назад»

- **WHEN** в меню настроек пользователь нажимает «Назад»
- **THEN** отправлено «Возврат в главное меню» с главной клавиатурой, состояние пользователя очищено

### Requirement: Некорректный ввод в настройках

Произвольное сообщение в состоянии `menu` **SHALL** получать подсказку выбрать значение из клавиатуры; сценарий остаётся активным.

#### Scenario: Посторонний текст

- **WHEN** в меню настроек пользователь вводит «привет»
- **THEN** отправлено сообщение об ошибке с подсказкой и клавиатурой настроек, сценарий остаётся активен

### Requirement: Не перехватывать сценарии других команд

Обработчик `/settings` **SHALL** возвращать `None`, если у пользователя активен сценарий другой команды (`context.is_active()` и `state_info["command"] != "/settings"`). Системная команда «Отмена» продолжает перехватываться `CancelHandler` глобально.

#### Scenario: /settings внутри чужого сценария

- **WHEN** пользователь в активном сценарии `/edit` вводит `/settings`
- **THEN** обработчик `/settings` возвращает `None`, сообщение обрабатывается сценарием `/edit`

#### Scenario: Отмена работает глобально

- **WHEN** пользователь в меню настроек вводит «Отмена»
- **THEN** `CancelHandler` сбрасывает состояние и выводит сообщение об отмене

### Requirement: Скорость чтения по периоду пользователя

Скорость чтения **SHALL** вычисляться как среднее количество страниц в день за окно последних N календарных дней, где N равно периоду скорости чтения пользователя. Начало окна **SHALL** не предшествовать дате начала чтения книги; деление на календарные дни окна. Период **SHALL** применяться во всех местах использования скорости чтения: детальная информация о книге, мини-статистика обновления прогресса, прогноз завершения, порог скачка прогресса. Строка статистики **SHALL** выводиться как «Среднее за N дней: X стр/день».

#### Scenario: Среднее за 7 дней

- **WHEN** период пользователя 7, за последние 7 календарных дней прочитано 70 страниц
- **THEN** скорость чтения равна 10.0 стр/день

#### Scenario: Окно не раньше начала чтения

- **WHEN** период 14, книга начала читаться 5 дней назад, прочитано 50 страниц
- **THEN** скорость чтения равна 10.0 (50 / 5 дней)

#### Scenario: Дефолт при отсутствии настройки

- **WHEN** у пользователя нет строки в `user_settings`
- **THEN** окно усреднения 30 дней

#### Scenario: Строка в деталях книги

- **WHEN** период пользователя 14, пользователь открывает детали книги со статистикой
- **THEN** сообщение содержит строку «Среднее за 14 дней: ... стр/день»

#### Scenario: Прогноз по периоду

- **WHEN** период 7, скорость чтения 10 стр/день, осталось 100 страниц
- **THEN** прогноз «Осталось: 10 дн.»

#### Scenario: Порог скачка по периоду

- **WHEN** период 7, скорость чтения 10 стр/день, пользователь вводит прирост 80 страниц
- **THEN** порог скачка равен 70 (7 * 10), обновление требует подтверждения

### Requirement: Кнопка и подсказка /settings

Главная клавиатура **SHALL** содержать кнопку `/settings` (последний ряд), справка `/help` **SHALL** содержать строку о команде.

#### Scenario: Кнопка в главной клавиатуре

- **WHEN** пользователь видит главную клавиатуру
- **THEN** последний ряд содержит `/settings` рядом с `/goal`, `/stats`, `/help`

#### Scenario: Строка в /help

- **WHEN** пользователь вводит `/help`
- **THEN** список команд содержит `/settings`
