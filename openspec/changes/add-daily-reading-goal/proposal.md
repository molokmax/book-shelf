## Why

Пользователь хочет поддерживать привычку чтения через измеримую цель «читать N страниц в день» (issue #10). Данные о прочитанных страницах уже накапливаются в `read_stats`, но механизма цели нет: нельзя задать норму, увидеть прогресс за сегодня и получить подтверждение её выполнения.

## What Changes

- Новая команда `/goal` с меню из трёх действий: просмотр цели, установка, отключение. Сейчас цель одна (страниц в день), меню сразу работает с ней; при появлении других типов целей добавится шаг выбора цели.
- Новая таблица `goals` (`kind`, `target` на пользователя) для хранения дневной цели; сейчас поддерживается единственный `kind = "daily_pages"`.
- Миграция `read_stats`: добавляется колонка `user_id` (заливка из `books`), чтобы считать страницы за день по пользователю без join и не терять счётчик при удалении книги.
- В сообщении об успешном обновлении прогресса добавляется строка о дневной цели (`Цель на день: X/Y стр.`), а при пересечении порога — поздравление. Если цель не установлена, сообщение не меняется.
- Кнопка `/goal` в главной клавиатуре, строка в `/help`, термины в `CONTEXT.md`, упоминание в `README.md`.
- В `AGENTS.md` фиксируется механизм, по которому обработчик не перехватывает сообщения из активного сценария другой команды.

## Impact

- `src/core/models.py` — модель `Goal`, поле `user_id` у `ReadStat`.
- `src/core/database.py` — таблица `goals`; запись `user_id` в `read_stats`.
- `src/core/migrations.py` — миграция `read_stats.user_id` с заливкой из `books`.
- `src/core/repository.py` — `GoalRepository`; `ReadStatsRepository` с `user_id` и агрегацией страниц по пользователю.
- `src/core/services.py` — `GoalService` (установка/отключение/статус/страницы за сегодня); `update_book_progress` передаёт `user_id` в статистику.
- `src/vk_bot/handlers/goal.py` — новый обработчик `/goal` (меню, просмотр, установка, отключение).
- `src/vk_bot/flows/progress_update.py` — строка о цели и поздравление в финальном сообщении обновления прогресса.
- `src/vk_bot/keyboards.py` — кнопка `/goal` в главной клавиатуре.
- `src/vk_bot/handlers/help.py` — строка о команде `/goal`.
- Тесты: обработчик `/goal`, сервис целей, миграция, вывод строки о цели в прогрессе.
