## Context

Команда `/start` — единственная, обрабатываемая вне `CommandRouter` через `if-elif` в `VkBookShelfBot.handle_event()`. Остальные команды используют `AbstractCommandHandler` с приоритетной маршрутизацией. Текущая реализация `handle_start_command` — простая функция в `start.py`, отправляющая приветственное сообщение с главной клавиатурой.

## Goals / Non-Goals

**Goals:**
- Создать `StartHandler(AbstractCommandHandler)` с наивысшим приоритетом
- Перенести логику приветствия в `StartHandler.handle()`
- Зарегистрировать `StartHandler` в `CommandRouter`
- Удалить ручную обработку `/start` из `handle_event()`
- Удалить старый файл `start.py`

**Non-Goals:**
- Не меняется текст приветствия и поведение команды
- Не затрагиваются другие команды или система роутинга

## Decisions

- **Приоритет 1000** — наивысший, чтобы `/start` обрабатывался раньше всех (в т.ч. раньше `CancelHandler` с priority=100)
- **Команды**: `["/start", "start", "начать"]` — полное покрытие всех вариаций вызова
- **Новый файл**: `start_handler.py` (по аналогии с `add_handler.py`, `help_handler.py`)
- **Старый файл `start.py` удаляется** — вся логика переносится в класс

## Risks / Trade-offs

- **[Низкий] Конфликт приоритетов** — приоритет 1000 гарантирует обработку раньше всех. В будущем, если понадобится ещё более высокий приоритет, достаточно скорректировать число.
- **[Низкий] Пропуск команды при ошибке импорта** — стандартная обработка ошибок в `CommandRouter.route()` логирует и возвращает `None`, команда не теряется.

## Migration Plan

1. Создать `StartHandler` в новом файле
2. Зарегистрировать в `bot.py` перед остальными обработчиками
3. Удалить блок `if command == "/start"` из `handle_event()`
4. Удалить `start.py`
5. Проверить, что команда `/start` работает через роутер
