# Spec Delta

## MODIFIED Requirements

### Requirement: Исключения показа фразы

Мотивационная фраза **SHALL** не показываться, если настройка «Мотивация» выключена, обновление ничего не изменило («Прогресс не изменился») или в сообщение уже добавлено поздравление о выполнении дневной цели либо новом достижении. Сбой выбора фразы **SHALL** не ломать отправку подтверждения прогресса.

#### Scenario: Мотивация отключена

- **WHEN** пользователь с выключенной настройкой «Мотивация» обновляет прогресс книги
- **THEN** подтверждение прогресса отправляется без мотивационной фразы

#### Scenario: Прогресс не изменился

- **WHEN** пользователь вводит текущую страницу без изменений
- **THEN** сообщение начинается с «ℹ️ Прогресс не изменился», фраза не добавляется

#### Scenario: Выполнение дневной цели

- **WHEN** обновление прогресса приводит к выполнению дневной цели
- **THEN** показывается «🎉 Цель на день выполнена!», случайная фраза не добавляется

#### Scenario: Получение достижения

- **WHEN** обновление прогресса приводит к получению одного или нескольких достижений
- **THEN** блок новых достижений показывается, а случайная мотивационная фраза не добавляется

#### Scenario: Дневная цель и достижение одновременно

- **WHEN** одно обновление прогресса впервые выполняет дневную цель и выдаёт достижение
- **THEN** сообщение содержит оба поздравления без случайной мотивационной фразы

#### Scenario: Сбой сервиса мотивации

- **WHEN** сервис мотивации возвращает ошибку при применении прогресса
- **THEN** подтверждение прогресса доставляется, сообщения об ошибке пользователю нет
