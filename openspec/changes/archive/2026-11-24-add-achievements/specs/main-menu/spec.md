# Spec Delta

## MODIFIED Requirements

### Requirement: Открытие подменю «Ещё»

Кнопка «Ещё» **SHALL** открывать экран «Ещё»: сообщение со списком остальных команд с краткими описаниями и клавиатурой подменю. Открытие **SHALL NOT** создавать состояние диалога пользователя.

#### Scenario: Нажатие «Ещё»

- **WHEN** пользователь без активного сценария нажимает «Ещё»
- **THEN** бот отправляет экран «Ещё» со списком `/edit`, `/export`, `/goal`, `/stats`, `/settings`, `/achievements` с краткими описаниями и клавиатурой подменю; состояние диалога не создаётся

#### Scenario: Ручной ввод не открывает подменю

- **WHEN** пользователь отправляет текстом «ещё» или «еще»
- **THEN** сообщение не маршрутизируется в обработчик навигации: подменю открывается только кнопкой

### Requirement: Состав подменю «Ещё»

Подменю **SHALL** содержать `/edit`, `/export`, `/goal`, `/stats`, `/settings`, кнопку «Достижения» и кнопку «Назад»: ряд 1 `/edit`, `/export`, `/goal`; ряд 2 `/stats`, `/settings`, «Достижения»; ряд 3 «Назад». Кнопка «Достижения» **SHALL** вызывать `/achievements`, а кнопка «Назад» **SHALL** иметь payload `{"command": "/back"}`.

#### Scenario: Раскладка подменю

- **WHEN** бот отправляет экран «Ещё»
- **THEN** клавиатура содержит три ряда: `/edit`, `/export`, `/goal`; затем `/stats`, `/settings`, «Достижения»; затем «Назад» с payload `/back`

#### Scenario: Открытие достижений из подменю

- **WHEN** пользователь нажимает «Достижения»
- **THEN** вызывается команда `/achievements`

### Requirement: Приветствие и справка

`/start` **SHALL** перечислять команды главного меню и упоминать кнопку «Ещё». `/help` **SHALL** содержать строки о `/details` и `/achievements`.

#### Scenario: Приветствие соответствует главному меню

- **WHEN** пользователь вводит `/start`
- **THEN** текст перечисляет `/add`, `/progress`, `/list`, `/details`, `/help` и упоминает кнопку «Ещё» с остальными командами

#### Scenario: Справка упоминает /details

- **WHEN** пользователь вводит `/help`
- **THEN** список команд содержит `/details`

#### Scenario: Справка упоминает /achievements

- **WHEN** пользователь вводит `/help`
- **THEN** список команд содержит `/achievements` с описанием каталога достижений
