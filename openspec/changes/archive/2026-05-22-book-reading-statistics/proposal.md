## Why

Пользователям понадобится видеть, сколько страниц они уже прочитали в каждой книге и как быстро они читают, чтобы планировать завершение чтения и получать прогнозы.

## What Changes

- Добавить модель и хранение статистики чтения (кол-во прочитанных страниц, дата обновления) для каждой книги.
- Реализовать сервис, который будет обновлять эту статистику при изменении прогресса книги.
- Сохранять агрегированные данные в SQLite базе данных `data/book_stats.db`.
- Подготовить инфраструктуру для будущих выводов статистики за неделю, две недели, месяц и прогнозов.

## Capabilities

### New Capabilities
- `book-reading-statistics`: Отслеживание количества прочитанных страниц по каждой книге, накопление данных за период и расчёт прогноза завершения книги.
