## Context

Пользователи команды `/edit` сейчас видят полный список всех книг, что затрудняет редактирование записи из конкретного подсписка (прочитанные, планируемые и т.п.). Требуется добавить интерактивный выбор подсписка перед редактированием, аналогично тому, как это реализовано в команде `/list`.

## Goals / Non-Goals

**Goals:**
- Позволить пользователю выбрать один из предопределённых подсписков книг перед переходом к редактированию.
- Переиспользовать существующую инфраструктуру клавиатур и выбора списков из команды `/list`.
- Обновить обработчик `edit` и соответствующие тесты.

**Non-Goals:**
- Не менять схему хранения книг в базе данных.
- Не добавлять новые типы фильтрации, кроме выбора предопределённых подсписков.

## Decisions

- **Использовать общий механизм выбора списка** (`utils.helpers.select_book_list` и готовые клавиатуры) для команды `/edit`. Это уменьшит дублирование кода и сохранит единый стиль UI.
- **Добавить отдельный обработчик `edit-select-list`** в `src/bot/handlers/edit.py`, который сначала запрашивает подсписок, а затем переходит к обычному процессу редактирования.
- **Использовать клавиатуры** из `src/bot/keyboards.py`.
- **Не менять схему БД**: выбранный подсписок будет формироваться на уровне запросов к репозиторию (`repository.get_books_by_filter`).
- **Тесты**: добавить случаи в `tests/test_edit_handler.py` для нового диалога выбора и проверки корректного фильтра.

## Risks / Trade-offs

- **Риск UI‑конфликта**: добавление новой клавиатуры может конфликтовать с текущими клавиатурами, если их ID пересекаются. mitigated: использовать уникальные `callback_data` и протестировать совместимость.
- **Потенциальная задержка**: дополнительный запрос к базе данных перед редактированием может увеличить время отклика. mitigated: запрос будет быстрым, так как использует индексированный столбец `status`.
- **Потеря обратной совместимости**: пользователи, привыкшие к преждём поведению `/edit`, могут быть смущены новым шагом. mitigated: добавить пояснительное сообщение о выборе подсписка.
- **Тестовое покрытие**: необходимо обновить тесты, иначе покрытие может упасть. mitigated: добавить unit‑тесты для нового пути.
