## Why

Пользователи команды `/edit` вынуждены просматривать полный список книг, хотя часто требуется отредактировать запись из конкретного подсписка (например, прочитанные, планируемые). Это усложняет взаимодействие и ухудшает UX.

## What Changes

- Добавить интерактивный выбор подсписка книг перед переходом к редактированию, аналогично тому, как это реализовано в команде `/list`.
- Обновить обработчик `edit` для получения выбранного подсписка и отображения соответствующего списка книг.
- Добавить сообщения‑подтверждения о выбранном подсписке.

## Capabilities

### New Capabilities
- `edit-select-list`: позволяет пользователю выбирать один из предопределённых подсписков книг перед редактированием.

### Modified Capabilities
- *none*

## Impact

- Изменения в `src/bot/handlers/edit.py` (или аналогичном файле) для реализации выбора подсписка.
- Обновление тестов в `tests/test_edit_handler.py` для нового диалога выбора.
