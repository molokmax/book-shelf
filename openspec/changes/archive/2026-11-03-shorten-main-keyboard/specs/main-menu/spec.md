# Specification for main-menu

## Purpose

Спецификация описывает главное меню VK-бота Book Shelf: состав самых востребованных команд, подменю «Ещё» с остальными командами и навигацию между меню.

## ADDED Requirements

### Requirement: Состав главного меню

Главное меню **SHALL** содержать шесть кнопок в двух рядах: `/progress`, `/details`, `/list` (ряд 1) и `/add`, `/help`, «Ещё» (ряд 2). Кнопки команд **SHALL** отправлять текст команды без payload; кнопка «Ещё» **SHALL** иметь payload `{"command": "/more"}`.

#### Scenario: Раскладка главного меню

- **WHEN** бот отправляет сообщение с главной клавиатурой
- **THEN** ряд 1 содержит `/progress`, `/details`, `/list`; ряд 2 содержит `/add`, `/help`, «Ещё»

#### Scenario: Кнопки команд остаются текстовыми

- **WHEN** пользователь нажимает `/progress` в главном меню
- **THEN** боту отправляется команда `/progress` без payload

### Requirement: Открытие подменю «Ещё»

Кнопка «Ещё» **SHALL** открывать экран «Ещё»: сообщение со списком остальных команд с краткими описаниями и клавиатурой подменю. Открытие **SHALL NOT** создавать состояние диалога пользователя.

#### Scenario: Нажатие «Ещё»

- **WHEN** пользователь без активного сценария нажимает «Ещё»
- **THEN** бот отправляет экран «Ещё» со списком `/edit`, `/export`, `/goal`, `/stats`, `/settings` с краткими описаниями и клавиатурой подменю; состояние диалога не создаётся

#### Scenario: Ручной ввод не открывает подменю

- **WHEN** пользователь отправляет текстом «ещё» или «еще»
- **THEN** сообщение не маршрутизируется в обработчик навигации: подменю открывается только кнопкой

### Requirement: Состав подменю «Ещё»

Подменю **SHALL** содержать `/edit`, `/export`, `/goal`, `/stats`, `/settings` и кнопку «Назад»: ряд 1 `/edit`, `/export`, `/goal`; ряд 2 `/stats`, `/settings`, «Назад». Кнопка «Назад» **SHALL** иметь payload `{"command": "/back"}`.

#### Scenario: Раскладка подменю

- **WHEN** бот отправляет экран «Ещё»
- **THEN** клавиатура содержит `/edit`, `/export`, `/goal`, `/stats`, `/settings` и «Назад» с payload `/back`

### Requirement: Возврат в главное меню

Кнопка «Назад» **SHALL** возвращать пользователя в главное меню: сообщение «Главное меню» с главной клавиатурой. После выполнения команды из подменю пользователь **SHALL** видеть главную клавиатуру (текущее поведение обработчиков команд).

#### Scenario: Нажатие «Назад»

- **WHEN** пользователь на экране «Ещё» нажимает «Назад»
- **THEN** бот отправляет «Главное меню» с главной клавиатурой

#### Scenario: Команда из подменю завершается возвратом в главное меню

- **WHEN** пользователь на экране «Ещё» нажимает `/export` и экспорт завершается
- **THEN** сообщение с результатом содержит главную клавиатуру

### Requirement: Не перехватывать чужие сценарии

Обработчик навигации **SHALL** возвращать `None`, если у пользователя активен сценарий другой команды. Системная команда «Отмена» продолжает перехватываться `CancelHandler` глобально.

#### Scenario: «Ещё» внутри чужого сценария

- **WHEN** пользователь в активном сценарии `/add` нажимает «Ещё» (клавиатура осталась от предыдущего сообщения)
- **THEN** обработчик навигации возвращает `None`, сообщение обрабатывается сценарием `/add`

#### Scenario: Отмена работает глобально

- **WHEN** пользователь вводит «Отмена»
- **THEN** `CancelHandler` сбрасывает состояние и выводит сообщение об отмене

### Requirement: Приветствие и справка

`/start` **SHALL** перечислять команды главного меню и упоминать кнопку «Ещё». `/help` **SHALL** содержать строку о `/details`.

#### Scenario: Приветствие соответствует главному меню

- **WHEN** пользователь вводит `/start`
- **THEN** текст перечисляет `/add`, `/progress`, `/list`, `/details`, `/help` и упоминает кнопку «Ещё» с остальными командами

#### Scenario: Справка упоминает /details

- **WHEN** пользователь вводит `/help`
- **THEN** список команд содержит `/details`
