## Why

Пользователям неудобно просматривать полный список книг, когда их количество велико. Нужно предоставить возможность быстро отфильтровать список по статусу или тегам, чтобы сократить количество выводимых записей.

## What Changes

- Модернизировать обработчик команды `list` в `src/bot/handlers/list.py`.
- Добавить клавиатуру с четырьмя вариантами: "По статусу", "По тегам", "Все" и "Отмена".
- При выборе "По статусу" бот запрашивает статус (кнопки для каждого статуса + отмена) и отображает книги с выбранным статусом.
- При выборе "По тегам" бот запрашивает тег (кнопки всех используемых тегов + отмена) и отображает книги с выбранным тегом.
- Реализовать поддержку фильтрации в сервисе `BookService` (`src/core/services.py`) и репозитории (`src/core/repository.py`).
- Обновить клавиатуры в `src/bot/keyboards.py` для новых вариантов и отмены.

## Capabilities

### New Capabilities
- `filter-books-list`: Позволяет пользователю фильтровать список книг по статусу или тегам через интерактивные клавиатуры.

### Modified Capabilities
- _none_

## Impact

- Изменения затрагивают слой бота (`handlers/list.py`, `keyboards.py`) и бизнес‑логика (`services.py`, `repository.py`).
- Добавляются новые запросы к базе SQLite, но структура базы не меняется.
- Требуется обновить тесты для новых сценариев отображения списка.
