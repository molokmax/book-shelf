## Почему

Текущая команда `details` выводит полный список всех книг, что становится проблемой при больших библиотеках. Пользователю приходится вручную искать нужную книгу в огромном списке. Добавление интерактивного механизма фильтрации, аналогичного `edit`, позволит быстро отобрать книги по статусу, тегу, автору и т.д., улучшив удобство и согласованность команд.

## Какие изменения

- Внедрить в обработчик `details` интерактивный выбор фильтра (по статусу, тегу, автору и прочим атрибутам).
- Предоставить возможность пользователю увидеть полный список своих книг с помощью кнопки "Все" - также как в команде edit.
- Обновить тесты: добавить тесты для нового пути фильтрации в `tests/test_details_filter.py`.

## Возможности

### Новые возможности
- `details-filter`: Добавление слоя фильтрации в команду `details`, аналогичного использованию в `edit`. Эта возможность потребует:
  * Общей вспомогательной функции для построения условий фильтра.
  * Обновлённого обработчика `details`, применяющего фильтр перед выводом списка.

### Модифицированные возможности
- *Нет* – текущие возможности не меняются.

## Влияние

- **Код**: изменения в `src/vk_bot/handlers/details.py` и добавление функции в `src/utils/helpers.py`.
- **Опыт пользователя**: пользователи получат короткий отфильтрованный список вместо громоздкого полного списка.
- **Тестирование**: новые юнит‑тесты в `tests/test_details_filter.py` проверят корректность фильтрации.
