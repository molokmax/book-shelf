## Context

Текущая команда `details` выводит полный список всех книг, что затрудняет поиск в больших библиотеках. Необходимо добавить интерактивный механизм фильтрации, аналогичный `edit`, позволяющий пользователю быстро отбирать книги по статусу, тегу, автору и другим атрибутам.

**Новый шаг:** Перед выводом списка бот предлагает выбрать режим отображения:
- По статусу
- По тегам
- Все
- Отмена

Используется клавиатура из `src/bot/keyboards.py`. При выборе «По статусу» показывается список статусов, аналогично `edit.py`. При выборе «По тегам» — список доступных тегов.

## Goals / Non-Goals

Текущая команда `details` выводит полный список всех книг, что затрудняет поиск в больших библиотеках. Необходимо добавить интерактивный механизм фильтрации, аналогичный `edit`, позволяющий пользователю быстро отбирать книги по статусу, тегу, автору и другим атрибутам.

## Goals / Non-Goals

**Goals:**
- Реализовать интерактивный фильтр в обработчике `details`.
- Предоставить кнопку "Все" для вывода полного списка книг.
- Обновить тесты, покрывающие новый путь фильтрации.

**Non-Goals:**
- Не изменять текущую логику вывода без фильтра.
- Не добавлять новые команды, лишь расширить существующую.

## Decisions

- Использовать существующие сервисы для получения отфильтрованных книг (смотри `handlers/edit.py`).
- Интерактивный выбор будет реализован через клавиатуру VK Bot, аналогично обработчику `edit`.
- Фильтрация будет применяться перед формированием списка книг, используя уже существующие модели данных.

## Risks / Trade-offs

- **Risk:** Сложность поддержания фильтра при изменении модели книги.
  **Mitigation:** Фильтрация будет работать через абстрактный слой, использующий свойства модели, что упрощает будущие изменения.

- **Risk:** Возможные задержки в ответе бота при больших библиотеках.
  **Mitigation:** Ограничить количество одновременно отображаемых книг и использовать пагинацию.
