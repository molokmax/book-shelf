# Specification for reading-streaks

## Purpose

Спецификация определяет текущий страйк пользователя — количество последовательных календарных дней с выполненной дневной целью чтения — и правила его пересчёта по истории текущей цели.

## Requirements

### Requirement: Выполненный день страйка

Система **SHALL** считать день выполненным, если сумма прочитанных пользователем страниц по всем книгам за календарный день в локальном времени сервера больше или равна текущей дневной цели.

#### Scenario: Страницы суммируются по всем записям дня

- **WHEN** дневная цель равна 50 страницам и в один день пользователь прочитал 20 страниц в одной книге, затем 15 и 15 страниц в других книгах
- **THEN** этот день считается выполненным для страйка

#### Scenario: Равенство цели засчитывается

- **WHEN** дневная цель равна 50 страницам и пользователь прочитал ровно 50 страниц за день
- **THEN** этот день считается выполненным для страйка

#### Scenario: Недостаточный прогресс не засчитывается

- **WHEN** дневная цель равна 50 страницам и пользователь прочитал 49 страниц за день
- **THEN** этот день не считается выполненным для страйка

### Requirement: Текущий страйк

Система **SHALL** определять текущий страйк как число подряд идущих выполненных дней, заканчивающихся сегодня, если сегодняшняя цель выполнена, иначе вчера. Если такой серии нет, страйк **SHALL** быть равен нулю.

#### Scenario: Выполнение сегодняшней цели продлевает серию

- **WHEN** цель выполнена вчера и позавчера, но не три дня назад, а сегодня пользователь также выполнил цель
- **THEN** текущий страйк равен 3 дням

#### Scenario: Незавершённое сегодня сохраняет вчерашнюю серию

- **WHEN** цель выполнена вчера и позавчера, но не три дня назад, а сегодня пользователь ещё не выполнил цель
- **THEN** текущий страйк равен 2 дням

#### Scenario: Пропущенный вчерашний день обнуляет непродолженную серию

- **WHEN** цель выполнена позавчера, но не выполнена вчера и ещё не выполнена сегодня
- **THEN** текущий страйк равен 0 дней

#### Scenario: Выполнение цели после пропуска начинает новую серию

- **WHEN** вчера цель была пропущена, а сегодня пользователь выполнил цель
- **THEN** текущий страйк равен 1 дню независимо от более ранней серии

### Requirement: Начало истории текущей цели

Система **SHALL** рассчитывать страйк только по дням текущей цели, начиная с календарного дня её создания. Прогресс, записанный до этого дня, **SHALL NOT** влиять на страйк.

#### Scenario: Дни до создания цели не учитываются

- **WHEN** пользователь выполнял бы текущую цель несколько дней до её создания, вчера после создания цели прогресса не было и сегодня цель ещё не выполнена
- **THEN** текущий страйк равен 0 дней

#### Scenario: День создания цели учитывается целиком

- **WHEN** цель 50 страниц создана в 18:00, а в тот же календарный день до создания цели пользователь уже прочитал 50 страниц
- **THEN** день создания считается выполненным и текущий страйк равен 1 дню

### Requirement: Пересчёт при изменении цели

При изменении дневной цели система **SHALL** пересчитывать выполненные дни по новому значению для всей истории текущей цели.

#### Scenario: Увеличение цели может сократить страйк

- **WHEN** вчера пользователь прочитал 40 страниц при цели 30, затем увеличил цель до 50 и сегодня ещё не выполнил её
- **THEN** текущий страйк равен 0 дней

#### Scenario: Уменьшение цели может продлить страйк

- **WHEN** вчера и сегодня пользователь прочитал по 40 страниц при цели 50, позавчера прогресса не было, затем он уменьшил цель до 40
- **THEN** текущий страйк равен 2 дням

### Requirement: Отключение и повторная установка цели

При отсутствии дневной цели система **SHALL NOT** предоставлять текущий страйк. После повторной установки цели расчёт **SHALL** начинаться с календарного дня её нового создания.

#### Scenario: Цель отключена

- **WHEN** пользователь отключает дневную цель
- **THEN** текущий страйк для него не определён

#### Scenario: Цель установлена повторно

- **WHEN** пользователь отключает цель, затем устанавливает её повторно в другой календарный день
- **THEN** дни прежней цели не участвуют в расчёте нового страйка
