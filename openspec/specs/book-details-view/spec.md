# Specification for book-details-view

## Purpose

Спецификация описывает команду `/details`: выбор фильтра книг, нумерованный выбор книги и просмотр её подробной информации со статистикой чтения.

## Requirements

### Requirement: Пользователь может просматривать детальную информацию о книге

Система **SHALL** позволять пользователю VK-бота выбрать книгу по фильтру (статус, тег, все книги) и просмотреть её детальную информацию.

#### Scenario: Выбор фильтра — по статусу
- **WHEN** пользователь вводит `/details` и выбирает «По статусу»
- **THEN** система показывает клавиатуру выбора статуса книги

#### Scenario: Пользователь применяет фильтр по статусу
- **WHEN** пользователь выбирает статус в интерактивном интерфейсе
- **THEN** система показывает нумерованный список только тех книг пользователя, которые соответствуют выбранному статусу

#### Scenario: Выбор фильтра — по тегам
- **WHEN** пользователь вводит `/details` и выбирает «По тегам»
- **THEN** система показывает клавиатуру выбора тега

#### Scenario: Пользователь применяет фильтр по тегу
- **WHEN** пользователь выбирает тег в интерактивном интерфейсе
- **THEN** система показывает нумерованный список только тех книг пользователя, которые содержат выбранный тег

#### Scenario: Выбор фильтра — все книги
- **WHEN** пользователь вводит `/details` и выбирает «Все»
- **THEN** система показывает нумерованный список всех книг пользователя без фильтрации

#### Scenario: Выбор книги и показ деталей
- **WHEN** пользователь вводит номер книги из представленного списка
- **THEN** система получает выбранную книгу и отправляет её детальную информацию, включая название, автора, теги, статус, общее количество страниц, количество прочитанных страниц, дату добавления, дату начала чтения и ссылку
- **AND** сообщение включает статистику чтения: количество страниц, прочитанных за неделю и за месяц, среднюю скорость чтения, а также прогноз срока и даты завершения, когда он доступен

#### Scenario: Введён некорректный номер книги
- **WHEN** пользователь вводит нечисловое значение или номер вне диапазона представленного списка
- **THEN** система сообщает об ошибке и остаётся на шаге выбора книги

#### Scenario: По выбранному фильтру нет книг
- **WHEN** после выбора статуса, тега или всех книг список оказывается пустым
- **THEN** система сообщает об отсутствии книг и завершает сценарий `/details`
