# Specification for stats-command

## Purpose

Спецификация описывает требования к команде `/stats` в VK-боте Book Shelf. Команда возвращает личную сводку чтения: общие показатели библиотеки, календарные периоды и прогнозы завершения книг.

## Requirements

### Requirement: Пользователь может получить общие показатели библиотеки

Система **SHALL** позволять пользователю VK-бота получить общие показатели только своей библиотеки одним сообщением без запуска многошагового сценария.

#### Scenario: Успешное получение сводки

- **WHEN** пользователь отправляет команду `/stats` или нажимает соответствующую кнопку
- **THEN** система отправляет сообщение, содержащее:
  - общее количество книг;
  - количество прочитанных книг;
  - количество книг в процессе чтения;
  - количество книг в статусе «Хочу прочитать»;
  - количество отложенных книг;
  - общее количество страниц;
  - сумму текущих значений прогресса в страницах;
  - взвешенный по объёму книг средний процент прогресса.

### Requirement: Сводка содержит календарные периоды и сравнения

Система **SHALL** показывать страницы за текущую календарную неделю, месяц и год, а также количество прочитанных книг за текущий календарный год. Границы определяются по локальному времени сервера; текущий день входит в каждый период.

Система **SHALL** вычислять страницы как сумму положительных изменений прогресса из статистики чтения. Текущий снимок прогресса книг для исторических периодов не используется.

Система **SHALL** показывать рядом с каждым периодическим показателем значение аналогичного предыдущего периода и абсолютную разницу. Предыдущий период заканчивается соответствующей текущей датой; если такой даты нет, используется его последний день.

#### Scenario: Сравнение незавершённых периодов

- **WHEN** пользователь запрашивает сводку в среду 25 ноября
- **THEN** неделя сравнивается с понедельником по среду прошлой недели
- **AND** месяц сравнивается с 1 по 25 октября
- **AND** год сравнивается с 1 января по 25 ноября прошлого года.

#### Scenario: Предыдущий период короче текущей даты

- **WHEN** соответствующая дата отсутствует в предыдущем периоде, например 31 марта сравнивается с февралём
- **THEN** предыдущий период заканчивается своим последним календарным днём.

#### Scenario: Подсчёт прочитанных книг за год

- **WHEN** система вычисляет количество книг за текущий или предыдущий год
- **THEN** учитываются только книги со статусом «Прочитал» и датой завершения внутри соответствующего периода
- **AND** книга без даты завершения не привязывается к году и не заменяет её датой добавления или обновления.

### Requirement: Сводка содержит прогнозы текущих книг

Система **SHALL** показывать все книги со статусом «Читаю» и дату завершения каждой книги. Книги сортируются по возрастанию прогнозируемой даты, книги без прогноза находятся в конце.

Для книги с незавершённым прогрессом система **SHALL** делить остаток страниц на собственную скорость книги за настроенный пользователем период и округлять число дней вверх. Если собственная скорость недоступна, система **SHALL** использовать общую скорость пользователя по всем книгам за тот же настроенный период. Дата определяется как сегодня плюс рассчитанное число дней.

#### Scenario: Недостаточно данных для прогноза

- **WHEN** собственная и общая скорость книги равны нулю
- **THEN** вместо даты отображается «Недостаточно данных».

### Requirement: Сводка содержит прогноз всей очереди запланированных книг

Система **SHALL** показывать одну дату завершения всех книг со статусом «Хочу прочитать». Длительность очереди вычисляется как сумма полного объёма `pages` этих книг, делённая на общую скорость пользователя, с округлением вверх.

Базовой датой очереди является самая поздняя дата завершения среди книг «Читаю». Если текущих книг нет, базовой датой является сегодня. Длительность очереди прибавляется к базовой дате.

#### Scenario: Общая скорость недоступна

- **WHEN** очередь не пуста, но общая скорость пользователя равна нулю
- **THEN** система сообщает, что данных для прогноза недостаточно.

#### Scenario: Очередь пуста

- **WHEN** у пользователя нет книг со статусом «Хочу прочитать»
- **THEN** система сообщает, что очередь пуста, и не строит прогноз.
