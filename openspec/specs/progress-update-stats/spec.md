# Specification for progress-update-stats

## Purpose

Спецификация описывает вывод мини-статистики чтения книги в финальном сообщении общего сценария обновления прогресса `/progress` VK-бота Book Shelf.

## Requirements

### Requirement: Мини-статистика после обновления прогресса

Система **SHALL** после успешного завершения обновления прогресса чтения книги отправлять пользователю сообщение с подтверждением и блоком мини-статистики по этой книге. Блок **SHALL** также показываться, если пользователь повторно ввёл текущую страницу и прогресс не изменился. Расчёт использует общий `ProgressUpdateFlow`, методы `ReadingStatsService` (`get_reading_stats`, `avg_pages_per_day`, `predict_days_to_completion`, `predict_completion_date`) и данные таблицы `read_stats`, включая только что записанные страницы.

#### Scenario: Успешное обновление прогресса с данными статистики

- **WHEN** пользователь в состоянии `waiting_for_progress_input` вводит корректный номер страницы в диапазоне `0..total_pages`, и `BookService.update_book_progress` выполняется успешно
- **THEN** система отправляет сообщение, содержащее подтверждение обновления прогресса и строки:
  - `Прогресс: {current_page}/{pages} ({percent}%)`, где `percent` — округлённый до целого процент прочитанного
  - `За неделю прочитано: {weekly} стр.`, где `weekly` — сумма `pages_read` из `read_stats` за недельный период
  - `За месяц прочитано: {monthly} стр.`, где `monthly` — сумма `pages_read` за месячный период
  - `Среднее за N дней: {avg:.2f} стр/день`, где N — настроенный пользователем период скорости чтения (7, 14 или 30 дней; по умолчанию 30), а окно усреднения не начинается раньше даты начала чтения книги
  - `Осталось: {days} дн.`, где `days = ceil(осталось_страниц / avg)`
  - `Дата завершения: {YYYY-MM-DD}`, где дата вычисляется как `today + days`
- **AND** строки `Осталось` и `Дата завершения` выводятся только для книги, которую ещё предстоит дочитать

#### Scenario: Прогресс не изменился

- **WHEN** пользователь повторно вводит текущую страницу книги
- **THEN** система отправляет уведомление «Прогресс не изменился» и блок мини-статистики, после чего завершает сценарий

#### Scenario: Недостаточно данных для оценки

- **WHEN** после успешного обновления прогресса незавершённой книги среднее число страниц в день за настроенный период равно нулю
- **THEN** система вместо строк о среднем значении, оставшихся днях и дате завершения выводит строку `Недостаточно данных для оценки завершения`, остальные строки блока статистики сохраняются

#### Scenario: Ошибка ввода не порождает статистику

- **WHEN** пользователь вводит нечисловое значение, отрицательное число или страницу вне диапазона `0..total_pages`
- **THEN** система отправляет только сообщение об ошибке и НЕ выводит блок мини-статистики

### Requirement: Общий хелпер форматирования блока статистики

Система **SHALL** содержать хелпер `format_progress_stats(book, weekly_pages, monthly_pages, avg_pages, days_to_completion, predicted_date, period_days)` в `src/utils/helpers.py`, возвращающий блок мини-статистики в порядке, зафиксированном в первом требовании. Формат строк совпадает с соответствующими строками `format_book_details`.

#### Scenario: Форматирование полного блока

- **WHEN** хелпер вызывается с `weekly_pages=20`, `monthly_pages=55`, `avg_pages=2.89`, `days_to_completion=78`, `predicted_date=date(2027, 1, 7)`, `period_days=30` и книгой с `current_page=55`, `pages=319`
- **THEN** результат содержит в указанном порядке строки `Прогресс: 55/319 (17%)`, `За неделю прочитано: 20 стр.`, `За месяц прочитано: 55 стр.`, `Среднее за 30 дней: 2.89 стр/день`, `Осталось: 78 дн.`, `Дата завершения: 2027-01-07`

#### Scenario: Форматирование при нулевом среднем

- **WHEN** хелпер вызывается для незавершённой книги с `avg_pages=0`, `days_to_completion=None` и `predicted_date=None`
- **THEN** результат содержит `Недостаточно данных для оценки завершения` и не содержит строк о среднем значении, оставшихся днях и дате завершения

#### Scenario: Форматирование с пользовательским периодом

- **WHEN** хелпер вызывается с `avg_pages=2.89` и `period_days=14`
- **THEN** результат содержит `Среднее за 14 дней: 2.89 стр/день` и не содержит `Среднее за 30 дней`

#### Scenario: Форматирование завершённой книги

- **WHEN** хелпер вызывается для книги с `current_page=pages`
- **THEN** результат не содержит строк `Осталось`, `Дата завершения` и `Недостаточно данных для оценки завершения`
