# Project Structure

This document provides an overview of the book-shelf project structure and describes the purpose of each directory and major file.

## Root Directory

- `.coverage`: Test coverage report generated by pytest
- `.env.example`: Example environment file with configuration variables
- `.gitignore`: Specifies intentionally untracked files to ignore
- `AGENTS.md`: Documentation for AI agents working with the project
- `DevNotes.md`: Development notes and internal documentation
- `LICENSE`: Project license information
- `pytest.ini`: Pytest configuration file
- `README.md`: Main project documentation
- `requirements.txt`: Python dependencies for the project
- `src/`: Main source code directory
- `data/`: Data storage directory
- `docs/`: Documentation directory
- `tests/`: Test files directory

## src/ - Main Source Code

### src/bot/ - Telegram Bot Implementation

- `bot.py`: Main bot initialization and configuration
- `handlers/`: Event handlers for different bot interactions
  - `commands.py`: Command handlers (e.g., /start, /help)
  - `messages.py`: Text message handlers
  - `callbacks.py`: Callback query handlers
  - `book/`: Book-related handlers
    - `add.py`: Book addition functionality
    - `delete.py`: Book deletion functionality
    - `edit.py`: Book editing functionality
    - `export.py`: Book export functionality
    - `list.py`: Book listing functionality
    - `progress.py`: Book progress tracking
    - `stats.py`: Book statistics
    - `status.py`: Book status management
- `keyboards/`: Keyboard layouts for bot interactions
  - `main.py`: Main keyboard layouts
  - `add_method.py`: Keyboard for book addition methods

### src/core/ - Core Application Logic

- `database.py`: Database connection and management
- `db.py`: Database operations and queries
- `models.py`: Data models and schemas
- `repository.py`: Repository pattern implementation for data access
- `services.py`: Business logic services

### src/utils/ - Utility Functions

- `config.py`: Configuration management
- `helpers.py`: Helper functions and utilities
- `litres_parser.py`: Parser for LitRes bookstore
- `logger.py`: Logging configuration

## data/ - Data Storage

- `books.json`: JSON file storing book collection data

## docs/ - Documentation

- `MIGRATION_GUIDE.md`: Database migration guide
- `project_structure.md`: Project structure documentation (this file)

## tests/ - Test Suite

- `test_book_add.py`: Tests for book addition
- `test_book_list.py`: Tests for book listing
- `test_book_progress.py`: Tests for book progress tracking
- `test_book_status.py`: Tests for book status management
- `test_litres_parser.py`: Tests for LitRes parser
- `pages/`: Test data for web scraping tests
  - `book_page_1.html`: Sample book page HTML
  - `book_page_2.html`: Sample book page HTML
